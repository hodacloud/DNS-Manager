# HodaCloud DNS Manager 🌐
پیشرفته ترین ابزار مانیتورینگ DNS با قابلیت مدیریت حرفه ای کوئری ها

## پیش نیازها 🔧

نصب وابستگی ها
```
sudo apt update && sudo apt install tshark -y 
```
# نصب و راه اندازی ⚡
```
bash <(curl -Ls https://raw.githubusercontent.com/hodacloud/DNS-Manager/main/dns_manager.sh)
```
راهنمای استفاده 📖
# 1. راه اندازی اولیه سیستم
▸ بعد از اجرای اسکریپت گزینه 1 را انتخاب کنید
▸ ساختار دایرکتوری و فایل های لازم ایجاد می شود
▸ دسترسی های امنیتی تنظیم می گردند.

# 2. شروع مانیتورینگ زنده
▸ برای شروع مانیتورینگ گزینه 2 را انتخاب کنید
▸ نمایش لحظه ای کوئری های DNS با فرمت:
   [زمان] [IP مبدا] --> [دامنه]
▹ برای توقف مانیتورینگ Ctrl+C بزنید

# 3. مشاهده آمار تاریخی
▸ مرتب سازی شده بر اساس بیشترین درخواست

# 4. مسدود کردن دامنه
▸ با انتخاب گزینه 4 نام دامنه را وارد کنید
▸ دامنه به لیست سیاه اضافه می شود
▸ کوئری های بعدی برای این دامنه ثبت نمی شوند.

# 5. خروج از برنامه
▸ با انتخاب گزینه 5 از برنامه خارج شوید
▸ پیغام خروج اختصاصی نمایش داده می شود
▸ تمام فرایندهای پس زمینه به درستی بسته می شوند.

# ویژگی های کلیدی ✨

🕵️♂️ مانیتورینگ زنده DNS با رنگ بندی پیشرفته

📊 سیستم آماری هوشمند با قابلیت مرتب سازی

🔒 سیستم بلاک لیست پیشرفته

📁 مدیریت خودکار لاگ فایل ها

🎨 رابط کاربری حرفه ای با پشتیبانی از Unicode

⚡ بهینه سازی شده برای سرورهای پرترافیک
